# DeskPet 아이디어 검토 기록

- 사용자가 GitHub 이슈(`idea` 라벨)로 올린 아이디어의 검토 결과를 날짜별로 쌓는 문서.
- 검토 절차와 판정 기준: 에이전트 스킬 `.claude/skills/review-ideas/SKILL.md`.
  - 에이전트에게 "아이디어 검토해 줘"라고 하면 이 스킬을 따른다.
- 판정은 네 가지다.

| 판정 | 라벨 |
|---|---|
| 수락 | `idea:accepted` |
| 정보 더 필요 | `idea:needs-info` |
| 나중에 | `idea:later` |
| 하지 않음 | `idea:declined` |

- 이슈에 댓글과 라벨을 올리는 일은 사용자 승인 뒤에만 한다.

### #2 모자 움직임 개선
- **요약:** 걷기·대기 동작에서 머리가 위아래로 움직이는데, 모자는 제자리에 있어 떠 보임.
- **이미 있는지:** 없음. 지금은 서 있는 이미지(`rotations`)로 잰 몸 꼭대기에 모자를 고정한다(`HatPlacement`, `BodyMetrics.height`). 동작 프레임마다 달라지는 머리 높이는 반영하지 않는다.
- **원칙:** 문제 없음 (그리기 개선).
- **구조:**
  - 스킨을 읽을 때 프레임마다 보이는 픽셀의 꼭대기를 함께 잰다. 이미 `SpriteAlphaScanner`로 픽셀을 읽고 있으니 재사용한다.
  - `PetAppearance`에 "지금 프레임의 머리 꼭대기"를 묻는 메시지를 더한다.
  - `HatPlacement`가 그 값을 쓴다.
  - Core에서 고치므로 맥·윈도우가 같이 바뀐다.
- **확인:** 23종 × 걷기·대기 프레임별 미리보기 PNG, 검사(프레임 꼭대기가 내려가면 모자도 내려감).
- **효과:** 모자를 쓴 펫이 걸을 때마다 보임. 수집 2단계 완성도.
- **구현 (2026-11-21):** 꼭대기 픽셀만 재면 머리 위로 뻗은 팔·무기에 속아서, 서 있는 그림의 머리 부분을 본으로 프레임마다 맞추는 방식(`HeadTracker`)으로 바꿨다. 설계 문서 6.21 머리 따라가기.
- **GitHub 반응:** 댓글 없이 ❤️만 (사용자 요청).

### #1 투척물 정확도 개선
- **요약:** 포인터 쫓기 모드에서 던지는 무기가 매번 포인터에 정확히 닿음. 가끔 빗나가게.
- **이미 있는지:** 없음. 지금은 던지는 순간의 포인터 자리를 그대로 겨냥한다(`ThrowBehavior` → `Pet.hurl(at:)`, `Projectile`).
- **원칙:** 문제 없음. 실행 중 비용 없음, 규칙(난수)만 쓴다.
- **주의:** "포인터 위치를 알고 정확히 던지는 점"이 가장 좋은 반응을 얻은 기능이다. 그래서 대부분은 맞히고 가끔만 빗나가게 한다.
- **구조:**
  - `ThrowBehavior`에서 겨냥점에 흩어짐을 더한다. 예: 65%는 지금처럼 명중, 35%는 포인터에서 30~80pt 빗나감.
  - 빗나가면 반짝임 대신 작은 먼지를 띄우고, 던진 펫이 가끔 😅.
  - 명중 🎯 반응은 그대로 둔다. Core에서 고치므로 맥·윈도우가 같이 바뀐다.
- **확인:** 검사(명중 비율이 정한 값 안팎, 빗나간 거리 범위, 화면 밖으로 안 나감).
- **효과:** 던질 때마다 보이고, 사람 같은 맛이 생긴다.
- **결정 (2026-11-20, 사용자):** 메뉴 "던지기 정확도" 4단계(늘·자주(기본)·가끔·엉망)에 캐릭터별 성격(`aim`)을 더하는 추천안. 설계 문서 6.11 던지기 정확도.
- **GitHub 반응:** 댓글 없이 ❤️만 (사용자 요청). #2도 ❤️.
